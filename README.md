# Tunisian-chef-platform-1
A platform for managing catering services and wedding dinner reservations.


## 1. Project Overview

A platform for **managing catering services** and _**wedding dinner reservations**_.


## 2. Technologies

- React
- TypeScipt
- Docker
- PostgreSQL

## 3. Prerequisites

- Node.js
- Docker
- Git


  ## 4. Installation

git clone [tunisian-chef-platform-1](https://github.com/Dhia-NAfti/tunisian-chef-platform-1.git)

cd tunisian-chef-platform-1

## 5. Run the Application

docker-compose up -d --build
